## Preface

This training is designed to get you from zero programming knowledge in FRC to programming robots by yourself. It’s important that through this training, you remember that it’s not possible to include everything in this guide. If you need more help on something, ask! Our ultimate goal on FEDS programming is getting you all as up and ready for comp-season programming as possible.

If you ever have a question on anything you're seeing, ask a more experienced programmer. Or, ask FEDSBot. FEDSbot is an amazing resource because it can figure out almost anything for you, and it bases its answers on what you actually need to know. It pulls straight from our code, and can help with anything you're learning about.

You will be given a Google Doc with one tab per lesson; each tab says what (if anything) to put there. Paste code as text, not screenshots.

For now, complete tabs until the all-capital **“STOP HERE.”** Thank you!
