## Your Robot Gets Ears 👂🤖

⏱ **About 3 minutes**

In Module 3 you built a robot with a **blueprint** (class), **skills** (methods) and a **memory** (fields). But there was one problem: *you* had to decide every move ahead of time, in `main`. The robot was like a wind-up toy that does the same dance every time you run it.

In Module 4, the robot learns to **listen**. You'll type commands while the program is running, and the robot will react right away, just like a real game.

| Lesson | New superpower |
|---|---|
| Imports and Scanner | The robot can **hear** what you type |
| If, Else If, Else | The robot can **decide** what to do |
| Switch Statements | The robot can **pick** from a menu of actions |
| While Loops and the Game Loop | The robot keeps listening **forever** (until you say stop) |
| Challenge: Console Robot Arena | All of it together, with walls! |

## Where We're Headed

By the end of this module you'll understand every line of **Step 2** of our robot game. Here's a sneak peek of what it looks like when you play it:

```text
Program started!
Enter a direction:
f = forward | b = back | l = left | r = right  | x = exit
f
 ===== Robot is moving Forward =====
f = forward | b = back | l = left | r = right  | x = exit
l
 ===== Robot is moving Left =====
f = forward | b = back | l = left | r = right  | x = exit
x
Exiting program
```

The lines that are just `f`, `l` and `x` are what the player typed. Everything else is the program talking back.

## Still Using Programiz

We'll keep using the **[Programiz Java Online Compiler](https://www.programiz.com/java-programming/online-compiler/)** with the same one-file layout as Module 3: `public class Main` on top, and `class Robot` (no `public`) underneath.

> 💡 **Typing input in Programiz:** When your program is waiting for input, click inside the **output panel on the right**, type your answer, and press **Enter**. If nothing seems to happen after you press Run, the program is probably waiting for you to type something!

### How to read expected output in this module

In each exercise, you'll see a list of **what to type** followed by the **expected output**. The expected output only shows what the *program* prints. In Programiz, the letters you type will *also* appear on screen, mixed in between those lines. That's normal.
