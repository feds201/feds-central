## Time to Build a Game 🎮🤖

⏱ **About 15 minutes**

Look how far you've come. In the Java Classes projects you wrapped a Kraken in a `MotorSubsystem`, built an `ArmSubsystem` with enums, getters and commands, and then split it into IO layers with an interface. That is real robot code, and it's genuinely hard.

It's also hard to *practice*. Every test needs a robot, a fresh battery (remember the 5-minute rule!) and a free mechanism. So for the next two modules we're stepping away from the hardware and building something you can run anywhere, on any computer: **a little robot you drive around a screen with your arrow keys.**

You already know how to write the classes. This time, the new stuff is everything *around* the classes: reading input, reacting to key presses, and drawing to the screen. Along the way you'll finally get the full story on a few things you've already seen in robot code without much explanation:

| You've seen this in robot code... | ...and you'll learn it here |
|---|---|
| `@Override` above `periodic()` in every subsystem | What `@Override` really does, and the `Object` class every class secretly extends (Module 3) |
| `currentState.equals(targetState)` in the Module 2 intake code | Why Strings and other objects get compared with `.equals()` and not `==` (Module 3) |
| `controller.x().onTrue(...)` in `RobotContainer` | **Event-driven programming**: "don't call us, we'll call you" (Module 4) |
| `new ArmIO() {}` in your IO project | **Anonymous classes**: a one-off class with no name (Module 4) |

### One file, more than one class

In your robot project, every `public class` lives in **its own file**: `RobotContainer.java`, `ArmSubsystem.java`, and so on. Think of it like each student getting their own locker.

Programiz only gives us **one file** (one locker). That's fine! We'll put `Main` at the top and put `Robot` underneath it, **without** the word `public`:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Program started!");
    }
}

class Robot {
    // the robot's blueprint goes here
}
```

Java is happy with that because only **one** class in the file is `public`, and it's the one that matches the file name (`Main`).

> 💡 **Remember:** The real game in our `Step` folders has `Main.java` and `Robot.java` as separate files, just like your robot project. In Programiz, just stack them in one file like above.

## 🛠 Warm-up: Build the Robot

You already know every piece of this from the Java Classes projects, so this is a quick warm-up, not a lesson. Write a `Robot` class underneath `Main` that has:

1. `private` `int` fields `x` and `y`, and a `private final int stepSize`.
2. A constructor that starts the robot at `(250, 250)` with a `stepSize` of `10`.
3. Four methods, `moveUp()`, `moveDown()`, `moveLeft()` and `moveRight()`. Each one changes `x` or `y` by `stepSize`, then prints the new position like `Moving UP - New position: (250, 240)`.
4. Getters `getX()` and `getY()`.

> ⚠️ **Heads up:** moving **up** makes `y` **smaller**. That's not a typo. On a computer screen, `y` counts *down* from the top, like line numbers on a page. You'll see why in Module 4 when the robot gets a window.

Use this `main` to test it:

```java
public class Main {

    public static void main(String[] args) {
        System.out.println("Program started!");

        Robot robot = new Robot();
        robot.moveRight();
        robot.moveRight();
        robot.moveUp();

        System.out.println("x is " + robot.getX());
    }
}
```

Expected output:

```text
Program started!
Moving RIGHT - New position: (260, 250)
Moving RIGHT - New position: (270, 250)
Moving UP - New position: (270, 240)
x is 270
```

```java
class Robot {
    private int x;
    private int y;
    private final int stepSize;

    public Robot() {
        x = 250;
        y = 250;
        stepSize = 10;
    }

    public void moveUp() {
        y -= stepSize;
        System.out.println("Moving UP - New position: (" + x + ", " + y + ")");
    }

    public void moveDown() {
        y += stepSize;
        System.out.println("Moving DOWN - New position: (" + x + ", " + y + ")");
    }

    public void moveLeft() {
        x -= stepSize;
        System.out.println("Moving LEFT - New position: (" + x + ", " + y + ")");
    }

    public void moveRight() {
        x += stepSize;
        System.out.println("Moving RIGHT - New position: (" + x + ", " + y + ")");
    }

    public int getX() {
        return x;
    }

    public int getY() {
        return y;
    }
}
```
