## Welcome to the Robot Garage 🤖

⏱ **About 5 minutes**

In Module 1 you learned the building blocks: variables, types, operators, `if`, `switch` and loops. Now we use them to **build something**: a little robot you can drive around a screen with your arrow keys.

### One file, two classes

In a "real" Java project, like our FRC robot code, every `public class` lives in **its own file**: `Main.java`, `Robot.java`, and so on. Think of it like each student getting their own locker.

Programiz only gives us **one file** (one locker). That's fine! We'll put `Main` at the top and put `Robot` underneath it, **without** the word `public`:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Program started!");
    }
}

class Robot {
    // the robot's blueprint goes here
}
```

Java is happy with that because only **one** class in the file is `public`, and it's the one that matches the file name (`Main`).

> 💡 **Remember:** When you see `Main.java` and `Robot.java` as separate files in this guide, that's how the real project is organized. In Programiz, just stack them in one file like above.

## The Front Door: `main`

Every Java program needs a place to start. That place is:

```java
public static void main(String[] args) {
```

Think of `main` as the **front door** of your program. When you press Run, Java walks in through this door and runs the lines inside it from top to bottom. Without a front door, Java just stands on the porch confused. 🚪

You don't need to understand `public static void` or `String[] args` yet. For now, read the whole line as "**start here**."
