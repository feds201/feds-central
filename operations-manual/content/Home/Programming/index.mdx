## 🧩 Robot Programming vs Non-Robot Programming

At FEDS 201, our programming team is split into two mighty forces — Robot Programming and Non-Robot Programming — like two brain hemispheres working in perfect sync (most of the time).

Robot Programming is all about precision, performance, and panic-proof code. They're the ones writing the core logic that makes the robot behave, react, and (hopefully) not explode. Think of them as the pilots of real-time systems — fast, focused, and fluent in Java.

Meanwhile, Non-Robot Programming is the quiet mastermind in the background, building the tools and platforms that give our team its strategic edge. From scouting apps to analytics dashboards to backend systems that probably deserve their own Netflix docuseries, this wing works year-round across a jungle of programming languages.
