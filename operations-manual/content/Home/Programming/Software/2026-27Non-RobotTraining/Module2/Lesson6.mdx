# Task 3: Build your own button

`buildCheckBoxFull` is the team's. Now make **your own**, from scratch, using a plain `ElevatedButton`.

**The spec:**
- It's called **Defense**. It remembers a `bool defense`, starting `false`.
- When `false`, it's **red** and says `Defense: NO`.
- When `true`, it's **green** and says `Defense: YES`.
- Tapping it **flips** the value. (`!` means NOT: `!true` is `false`.)

Try for **10 minutes** before you open the hint.

<details>
<summary>Stuck? Open the hint</summary>

```dart
ElevatedButton(
  style: ElevatedButton.styleFrom(
    backgroundColor: defense ? Colors.green : Colors.red,
  ),
  onPressed: () {
    setState(() {
      defense = !defense;
    });
  },
  child: Text(defense ? 'Defense: YES' : 'Defense: NO'),
),
```

The `? :` is a shortcut for if/else: *"if defense, green, otherwise red."*

</details>

✅ **Checkpoint:** it flips, changes color, and changes words.
