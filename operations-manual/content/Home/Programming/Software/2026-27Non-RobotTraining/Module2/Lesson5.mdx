# Lesson 5

## 🎯 Goal

Make **three small fixes** in the real app. Most real programming is small edits, and now you can find any file in seconds.

# Your fix routine

Every fix follows the same 5 steps:

1. **Find** it (Lesson 5)
2. **Change** one thing
3. **Hot Reload** (Run panel)
4. **Look** at the app. Did it change like you expected?
5. **Commit** it

> **Hot Reload** applies your change and keeps the app's current state. **Hot Restart** starts the app over. If you changed something and *nothing happened*, try a hot restart before you panic.

# Fix 1: Change a number in a variable

**The symptom:** the bottom area of the **home screen** (the panel that holds the buttons) should be a little taller.

**Find it:** the code that sets its height is in `home_page.dart`. Search for `50.0`.

1. Change `50.0` to `55.0`. Hot reload. ✅ **Checkpoint:** the panel is taller.
2. **Predict:** what happens if you change it to `40.0`? Try it.
3. You'll probably see **yellow-and-black stripes**. That's an **overflow**: the content doesn't fit in its box. Change it back to `55.0`.
