# Lesson 8

## 🎯 Goal

Learn a **system** for fixing bugs, use it on a page full of them, then turn your own checklist into a **real checklist in your app**.

Everybody's code breaks. Good programmers just have a plan.

# The Debug Checklist ✅

Go in order.

1. **Expected vs. happened.** What did you *want*? What *actually* happened?
2. **Read the error.** Start at the top. Click the blue file link.
3. **Red squiggles?** Hover over them and fix those first.
4. **What did I change last?** Open the **Commit** window, right-click your file, and choose **Show Diff**. The bug is usually in what's green or red.
5. **Check the usual suspects:** `;` · matching `()` and `{}` · quotes · spelling and CAPITALS · did I forget `setState`? · did I forget the `$`?
6. **Print it.** `print('cycles is $cycles');` shows up in the **Run** panel.
7. **Make it smaller.** Comment out code (`Ctrl + /`, Mac `Cmd + /`) until the bug disappears.
8. **Hot restart.** Still weird? Stop the app and run it again.
9. **15-minute rule.** Stuck for 15 minutes? **Ask.** Say what you expected, what happened, and what you tried.

# Task 3: Make a checklist in your app

Now turn the checklist into **real code**. On your Training Page, under the heading **`LESSON 10: CHECKLIST`**, make a checklist of **5 debug steps** (use your own words!).

1. Give each step its **own `bool` variable**, starting `false`.
2. Show each one with **`buildCheckBox`**, like this:

```dart
buildCheckBox('Read the error', readError, (bool value) {
  setState(() {
    readError = value;
  });
}),
```

3. Write a function that counts the steps **not done yet**:

```dart
int stepsLeft() {
  int left = 0;
  if (!readError) {
    left++;
  }
  // one more "if" for each of your other steps
  return left;
}
```

(`!` means NOT. `!readError` means "readError is false".)

4. Under the checklist, show a `Text`:
   - **All steps done!** in **green** when `stepsLeft()` is `0`
   - **N steps left** in **orange** otherwise

✅ **Checkpoint:** you can't see `All steps done!` until **all 5** boxes are ticked.
