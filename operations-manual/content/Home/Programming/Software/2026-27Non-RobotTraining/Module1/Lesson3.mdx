## What is a Server?

A server is a computer that receives a request from a personal computer and sends information back to the personal computer.

### Example

An easy example to think of is this:

Imagine you search **"Today's weather"** on your phone.

Your phone sends a request to a server.

The server receives the request and processes it.

The server decides which data to send and returns it back to your phone.

Your phone receives the data and displays today's weather.

In simple terms:

**Your device → Request → Server → Information → Your device**
